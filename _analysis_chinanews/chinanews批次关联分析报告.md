## 一、字段对比：结论——确实只差前 3 个 id 列，但有类型/空值适配点

JSON 共 23 个字段，与 `news` 表 24 列一一对应，**缺的列只有**：

| 缺失列 | 表属性 | 说明 |
|---|---|---|
| `id` | BigInt PK, autoincrement | 自增，插入时无需提供 |
| `story_id` | String(64), unique, NOT NULL | **必须生成**。已验证不是 sha256(url/title/url+title)，规则来自上游采集管线，需确认或定一个确定性约定（如 sha256(canonical_url)） |

| 字段 | JSON 现状 | 库内规则 | 适配方式 |

| `publish_date` | `"2026-03-03 23:18"` 带时间的字符串 | Date（仅日期） | 截断为日期 |
