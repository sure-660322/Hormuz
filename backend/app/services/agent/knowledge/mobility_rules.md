# 停留、相遇与事件关联规则

## 停留（ship_dwell）

停留段由构建参数快照决定（锚泊/漂航/慢速航行的速度阈值与位移半径），
查询层不可调整阈值，只读取既有派生层，不触发任何重建。返回零段是
「派生层内无该类型停留」的有效零结果；status=not_built 表示派生层尚未构建。

## 相遇（encounters）

当前 nnu_ais 批次的相遇派生层尚未构建。相遇是预计算的船对（构建阈值如 3 NM/30 min），最小距离是离散采样
近似，跨带投影有失真；接近不等于实际交互，绝不推导真实接触或因果。
max_distance_nm 只能小于等于构建阈值，超过会被拒绝而不是返回零结果。

## 事件—船舶关联（event_ship_links）

mentioned：新闻原文提及的船名，纯文本证据，尚未核对真实 AIS 船舶 ID。
observed：轨迹与事件代表点的时空邻近推断（当前七日 AIS 尚未重建），
不构成真实因果。两个方向（按事件查、按船反查）都只读取既有派生层。

## 数据健康（data-health）

各来源报位数/船数/覆盖区间/中位间隔 + 四张派生表行数/built_at/params/stale。
stale 仅为时间启发式；无源时间基准时 stale 为 null（不可判定）。
