# 海峡完整通行判定规则

## 门线口径

纬度 25.8–27.1°N 带内，经度从 56.2°E 一侧变为 56.7°E 另一侧（或反向）
视为完整穿越；两门线之间保留状态、不判定。口径出处
sim_ais_demo/tools/verify_news_alignment.py。

## 时间窗口

按完成侧首个报位时间 ∈ [closure_at, end_at) 筛选；封锁前进入、封锁后完成
也计入。该时间是观测完成时间，不是精确越线时刻。单次查询窗口最多 24 小时。

## 候选质量

长间隔（起止侧报位超过阈值）或疑似跳点的候选标为不确定候选，不能硬算为
完整通行；无报位或前置状态不足时报告覆盖不足，不能写成「没有船通过」。

## 统计口径

按 ship_id 去重计算船只数，通行次数单列；同一船多次穿越不重复计为多艘。
足够数据中匹配为 0 是有效结果。
