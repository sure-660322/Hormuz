# 当前业务数据交接包

2026-09-14 从本机当前数据库在只读一致性事务中导出。安装、导入和验证命令见 [数据库交接说明](../../../docs/database_setup.md)。

- ships.jsonl：30 艘教学模拟船。
- ship_positions.jsonl：9,354 条教学模拟船位，location 导入后由数据库生成。
- events.jsonl：65 个新闻聚合事件。
- news.jsonl：290 条报道记录及加工摘要（223 条关联事件，67 条无关联），保留来源链接，不包含原文全文。
- manifest.json：导出时间、数量和 SHA-256。数据库 ID 与外键保留。

新闻及坐标不证明模拟船与真实事件的因果关系，报道日期不等于事件发生时刻。此包不是真实 AIS 或数据库灾备，不含密码和数据库账户配置。文件使用来源信息仅用于教学核验，原报道权利仍归原来源。

维护者刷新入口：在确认本机数据可共享后执行 `python -m backend.handoff export`，再于独立空库导入验证；该命令覆盖此目录的四表快照，不修改数据库。不要把维护者 .env 或 pg_dump 备份放进本目录。
