## 当前行为

- 明确“显示/画出/绘制轨迹”“定位/高亮船位”时，从本轮成功的 `get_ship_track` 结果生成 `automatic` 动作；仅分析“移动了吗”等问题返回建议按钮。否定、失败、零报位、轨迹不足两点、截断、多目标/同名歧义不自动执行。位置允许单点，轨迹至少两点。
- `ship_position` 与 `ship_track` 均携带船 ID、UTC 起止、`source=nnu_ais`、`window_source`；位置动作另有已核实 `recorded_at`。前端重新读取有界报位和回放快照，展示最终快照的实际 AIS 报位时刻和回放帧时刻，二者可能不同。
- `map_context` 是可选请求字段，包含带时区的 `playback_at` 和可选 `target_ship_id`。参考 ID 来自最近一轮唯一动作或唯一成功工具目标；“它”仍须本轮工具重新核实。明确 ID/唯一历史指代可直接查该 ID，不把数字 ID 当名称/MMSI 模糊关键词。
- 时间优先级：高级设置的请求起止 > 问题中的两个完整 ISO 8601 时区端点 > “最近/过去/前 N 小时”（1–24；一天等于 24 小时）> 回放时刻附近默认 24 小时。后两者用数据库 `nnu_ais` 实际覆盖裁剪，通常取回放时刻之前；位于覆盖首帧时向后取最多 24 小时。时间源与工具/地图窗口一致。
- 不完整日期、缺时区、单时间点、“昨天”等未支持相对日期、非整数时长及超过 24 小时的相对窗口要求用户给完整时间，不默默猜日期。复杂自然语言日期尚未通用解析。
- 地图命令不复用历史回答正文推断现状；唯一参考 ID 以结构化上下文提供，仍重新查询工具。没有本轮工具证据时返回澄清，不复述旧窗口并声称地图已执行。模型正文与前端执行状态分开，以“地图操作”区反馈为准。
- 自动操作及聊天结果中的船舶定位按钮保持聊天面板。点击地图船只仍可进入详情。聚焦避开右侧/底部详情面板；船簇中首次选中目标会正确附加高亮样式。仅在快照就绪、目标选中、相应图层渲染、地图目标可见后提示完成。
- 可取消地图加载；取消/换船/改变目标帧使旧请求失效。新动作清除上一轮智能体目标与轨迹，失败不留旧高亮。手动选择的船保持原有交互入口。
