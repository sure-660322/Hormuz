# 智能体问题—能力矩阵（AG-01）

> 状态：已实现待评审（2026-09-21，分支 `kimi/ag01-sql01-contract`）。本文为需求固定文档，不含代码。
> 依据：当前 v3 契约见 [agent_integration.md](agent_integration.md)，现有四个工具为 query_strait_passages / search_ships / get_ship_track / get_event_context；MobilityDB 派生层口径见 [mobility_capability_plan.md](mobility_capability_plan.md)。
>
> 通用约定（适用于全部条目）：
> - 模拟船位与真实新闻相互独立；船名相同不得认定为同一实体，空间邻近不得推导真实因果。
> - 「报道日期」≠「事件日期」≠「精确发生时刻」；无时间或位置不得补造。
> - 「真实零结果」（范围内判定完成、匹配为 0）与「数据缺失/覆盖不足」必须区分；缺失只能报 no_data/partial，不能写成零。
> - 时间窗口带时区、统一 UTC、单次 ≤24 小时；观测完成时间不是精确越线时刻。
> - 统计数量以数据库实际查询为准，不由模型编造；历史批次数量（如 30 艘船、9,354 条报位、231 段停留、136 对相遇）仅为当前批次快照，回答中须注明批次。
> - 分类取值：existing_tool / new_deterministic_tool / text_to_sql / clarification / refuse / non_data_question。
