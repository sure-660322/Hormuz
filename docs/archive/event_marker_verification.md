## 发现与调整

数据库到API的40个有效代表点坐标逐条一致，未发现经纬度颠倒。原地图按36像素网格将靠近的同类事件合并到第一条的位置，会隐藏其他事件各自的位置；相同坐标不同类别则可能互相遮挡。

现已改为仅按完全相同的经纬度分组，不按屏幕距离移动/合并代表点。同坐标跨类别统一计数，点击列出各事件，选中后保留其类别和详情。40条事件共有34处坐标：一组6条、一组2条，其余32条独立绘制。

标记提示及详情增加地名代表点、区域代表点、多点中心说明。Nominatim也可能返回国家中心，结合已有geo_note中的coarse/国家中心说明标识为区域代表点。不把方法名当成精确地理位置保证。

## 已验证

- 数据库/API坐标不一致数：0。
- 浏览器DOM标记包含全部40个事件编号，34处坐标。
- 用已加载OpenStreetMap瓦片的z/x/y与DOM边界，独立计算Web Mercator投影，再与标记图形中心比较；34个标记最大误差0.673像素，属于Leaflet像素取整范围。
- 海峡区域中心6条不同类别事件可展开选择；选择市场类evt_049后详情正确且标记仍保留6条分组。
- 浏览器检查时无控制台错误/警告。
- `npm run build`、`npm run check:workbench`通过。

## 范围

修改地图分组和代表点提示，不修改数据库坐标，不新增多点绘制。验证的是当前入库代表点在底图上的绘制一致性，并未逐条重新地理编码或确认新闻真实事发位置。国家/区域中心及多点算术中心可能处在报道地点之间，不能用于精确事件距离或因果判断。
