## 数据

- 来源：[Natural Earth Admin 0 Countries 1:50m](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/)，[许可说明](https://www.naturalearthdata.com/about/terms-of-use/)为公共领域。
- 本地文件：`frontend/public/data/gulf-countries.geojson`，52,025字节、13个国家。使用已经概化的50m版本，只裁剪所需国家并移除无关属性；保留原始环、岛屿和分离领土，不另行独立简化相邻边以免制造缝隙。
- 来源地址、输入/输出SHA-256和处理方式保存在同目录 `gulf-countries.source.json`。生成脚本 `scripts/prepare_country_boundaries.py`。
- 页面仅在图层首次启用时请求本地GeoJSON，不访问外部边界服务；成功后复用内存数据。加载失败时开关旁提示，可关闭后重新开启重试；销毁地图时取消请求和监听。
- 这是概化参考边界，不是港口/岛礁级测绘数据；数据采用Natural Earth默认边界表达。高倍放大保持矢量线清晰，不会补造细节。

## 独立实现

- `frontend/src/services/countryLayer.ts` 管理SVG边界、国名、请求、显隐和清理。
- `frontend/src/domain/countryLabels.ts` 计算中文标签落点。优先采用Natural Earth给出的境内标签点；中心离开视野后，在可见国家多边形中寻找落点，考虑孔洞和分离领土。
- 国名不依赖底图语言。缩放3开始显示较大国家，阿联酋、以色列和黎巴嫩从4开始，科威特/卡塔尔/巴林从5开始；标签有碰撞避让，小比例尺可能隐藏小国名称。放大后恢复。未额外引入城市/港口文字，当前自定义层始终只有中文国名。
- 边界pane为250、中文文字为350，低于分析图形400和船舶/事件600；两层及其子元素均禁用指针命中，标签不接受键盘焦点。
- 打印保留SVG与中文DOM文本，并设置打印颜色和打印前后尺寸刷新；跟随当前开关，不改变原有打印入口。
