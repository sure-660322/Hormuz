# 新闻事件基础适配（2026-09-09）

> 本文保留9月9日阶段记录。9月13日起船舶已替换为同期新闻对应的30艘模拟批次，旧“8月回放/时段不重叠”描述不再代表当前数据；新闻独立浏览、无自动船舶关联的功能边界仍保留。当前状态见 [README](../README.md)，下一步见 [智能体接口规划](agent_integration.md)。

## 已实现

- `/events` 返回新表的中文字段、可空时间/坐标、报道日期、代表点说明、报道数量、视角和提及船名。默认按首次报道日期排序，不伪造发生时间。
- `/events/{event_id}/news` 按 `evt_001` 等业务编号返回关联新闻摘要、媒体、日期、视角和规范原文链接；未知事件404；不输出正文content。
- 前端保留现有布局，在读取API时建立轻量视图字段映射。65条事件可分类、排序、搜索和查看详情；25条无坐标事件不触发地图定位。
- 地图仅绘制40个具备代表点的事件，保留聚合与定位交互；详情明确提示区域中心、多点中心不等于精确事发地点。
- 详情按需加载关联报道，支持加载、失败重试、空结果，并取消过期请求，避免切换事件时显示上一条新闻。链接仅接受HTTP/HTTPS，在新标签打开。
- 原始时间文字优先显示。38个无event_datetime事件可正常阅读，不显示虚构的“待回放”。
- 新闻选择不再seek模拟船位；船舶回放时间变化不再清除事件详情。时间轴只展示模拟船位，不绘制新闻密度、刻度和下一事件入口。
- 停止新闻与模拟船舶的邻近列表、连线及半径混合计算；保留模拟船位范围查询。相关入口说明当前未关联，避免把未实现显示成“没有事件”。
- `/simulation/meta.event_count` 当前为0，表示模拟回放中没有事件；65条新闻事件由自己的接口计数。船舶150、船位14,400、帧数96保持原值。
- 分享中的选中事件使用业务event_id，减少重导后数字主键变化的影响；打印时间和坐标显示支持空值。
