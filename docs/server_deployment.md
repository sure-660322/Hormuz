## 交付方式

按用户要求，代码、Docker 配置与说明同步至 GitHub；新闻图片与地图瓦片作为同一私有仓库的发布附件，不将十余万个瓦片文件纳入 Git 对象。
含 AIS 的数据库包只在本地交付，不上传 GitHub。验证输出也仅保留本地。
程序由 Docker 构建同源前端、后端及知识库；不复制本机 .env、虚拟环境、原始 AIS 输入、模型密钥或数据库角色密码。
配套服务器生成新数据库密码和入口密码；数据库不开放主机端口，API 单 worker，内部受控 SQL/MCP 不随本包启用。

源应用库备份采用只读一致性快照，选择全部非扩展 public 业务表，保留表结构、ID/外键、序列、索引及地理生成列。
源库无 TimescaleDB 时序表；目标使用现有镜像 `mobilitydb/mobilitydb:17-3.5-1.3`，不携带未使用的 TimescaleDB 内部对象。
不执行源库迁移、导入、重建或清理。恢复限定独立空库，发现业务表即拒绝；它不是升级或覆盖已有数据库的工具。
